# AssistOps-
Multi-agent AI assistant built with LangGraph (Supervisor + RAG + Tools agents),  FastAPI, Qdrant vector store and n8n for event-driven orchestration.  Handles Slack/webhook triggers, CRM lookups, ticket creation and knowledge base Q&amp;A.  Full observability (LangSmith, structured JSON logs), pytest suite, HMAC-secured webhooks.
