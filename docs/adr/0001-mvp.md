# ADR 0001 — Première tranche verticale et responsabilités

Statut : accepté pour le socle ; interfaces métier à implémenter.

## Contexte

Le dépôt initial ne contient pas de code applicatif. La première tranche doit
se développer et se tester sans comptes métier ni appels IA payants.

## Décision

Monolithe Python modulaire avec factory FastAPI et configuration injectée.
PostgreSQL portera événements, conversations, approbations et audits ; Qdrant
portera l'index documentaire. Le socle sonde ces services mais ne crée encore
aucune table ou collection.

n8n gérera les connecteurs et l'enrichissement ; LangGraph possédera les décisions
des agents et leurs interruptions. Autorisation et validation resteront dans le
code métier, indépendantes des sorties du modèle.

`/health/live` indique que l'API répond. `/health/ready` exécute `SELECT 1` et
interroge Qdrant `/readyz` avec timeouts bornés. Une panne renvoie 503. Cette
readiness ne garantit pas l'existence future du schéma ou de l'index.

Les logs utilisent des noms de routes, jamais les corps, query strings, headers
d'authentification ou messages bruts d'exception. L'accès Uvicorn est désactivé
dans les commandes proposées. Les correlation IDs sont bornés et filtrés ; ils
servent au diagnostic, jamais à l'autorisation.

## Conséquences

Le socle se teste sans fournisseur IA. Les API métier seront simulées avant
raccordement réel. Production, migrations et rétention nécessiteront des décisions
supplémentaires. Le Compose fourni reste un environnement de développement local.
